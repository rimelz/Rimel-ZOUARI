# Rimel Zouari - Portfolio

Portfolio professionnel de Rimel Zouari, élève ingénieure en génie informatique spécialisée en Data Science & Intelligence Artificielle.

## 🚀 Déploiement automatique

Ce site est automatiquement déployé sur GitHub Pages via GitHub Actions à chaque push sur la branche `main`.

## 🛠️ Technologies

- HTML5
- CSS3 (avec animations avancées)
- JavaScript (Vanilla JS)
- Lenis (smooth scrolling)
- Canvas API (animations de fond)

## 📋 Sections

- **Profil** : Présentation et introduction
- **Expérience** : Stages professionnels
- **Formation** : Parcours académique
- **Compétences** : Technologies et soft skills
- **Certifications** : Certifications et formations
- **Langues** : Français et Anglais
- **Contact** : Coordonnées professionnelles

## 📦 Structure du projet

```
rimel/

```
